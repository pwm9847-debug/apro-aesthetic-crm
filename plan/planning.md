# 심미 보철 특화 치과 CRM 기획안 — "Proof-first CRM"

## Context
- 대상: 라미네이트·올세라믹 등 **심미 보철 환자**. 고관여·고가·비교쇼핑형. 결정 질문은 단 하나 — **"이 병원, 이거 많이 해봤나?"**
- 일반 치과 CRM(예약 리마인드, 생일문자, 리콜)은 이 질문에 답하지 못한다. 그래서 이 CRM의 중심축은 **"경험을 증명하는 엔진 + 비교 단계를 읽는 트래커"** 로 둔다.
- 현재 `crm/` 폴더는 비어 있음(신규 구축). 기술/연동 세부는 승인 후 확정.

## 핵심 컨셉 3가지
1. **Experience Ledger (경험 원장)** — 모든 케이스를 구조화 데이터로 쌓고, 상담 때 *환자 본인과 비슷한 케이스 수*를 즉시 증명.
2. **Decision Radar (결정 레이더)** — 환자가 어느 단계(탐색→비교→검증→결정)인지 행동 신호로 추정, 타이밍/메시지를 맞춤.
3. **Aesthetic Profile (심미 취향 카드)** — 환자의 취향을 데이터화해 "내 취향을 이해하는 병원"이라는 감도 형성.

## 1. 데이터 모델 (CRM의 뼈대)
- **Patient**: 기본정보, 유입경로, 동의 상태(민감정보/사진/마케팅 각각 분리), 결정권자(배우자·부모 등) 메모
- **Case(케이스)**: 시술종류(라미/올세라믹/크라운/잇몸성형 병행), 치아번호·개수, 재료·기공소, 술자, shade(전→후), 교합/변색/치열 난이도 태그, 소요 기간, 표준화 사진 세트(정면/측면/웃을때/교합면), 임시치아 기간
- **FollowUp 경과 데이터**: 1주/1개월/6개월/1·3·5년 경과 사진·상태·재방문 (파절/탈락/변색 여부)
- **AestheticProfile**: 선호 shade, 형태(라운드/스퀘어/내추럴), 투명도, 레퍼런스 이미지, "싫은 것" 목록
- **Touchpoint**: 모든 접점(광고 클릭, 블로그 열람, 카톡 문의, 전화, 예약, 내원, 링크 열람)을 시간순 이벤트로 저장
- **Objection(이탈/보류 사유)**: 가격·타병원 비교·시술 두려움·결정권자 설득·시기 — 코드화

## 2. "많이 해봤나?"에 답하는 장치 (차별화 핵심)
| 장치 | 설명 |
|---|---|
| **유사 케이스 매칭** | 환자 구강사진·희망사항 입력 → 치아 상태·난이도 태그로 유사 케이스 자동 검색. 상담 태블릿에 "본원 유사 케이스 N건 / 담당 원장 N건 / 5년+ 경과 N건" 표시. 수치는 실데이터에서 자동 산출(근거 보관) |
| **술자별 포트폴리오 뷰** | 상담 시 담당 원장의 누적·연도별 케이스, 난이도별 분포 |
| **Longevity Wall (장기 경과)** | 5년·10년 경과 케이스는 가장 강력한 증거. 경과 사진 수집을 CRM이 자동 리콜로 챙김(편리한 촬영 안내·소정 혜택) |
| **상담실 전용 열람** | 전후 사진은 의료법상 온라인 광고 제약이 크므로, **내원 상담 중 1:1 열람(별도 동의된 케이스만)** 을 기본 동선으로 설계 |
| **"타병원 갈 때 물어볼 체크리스트" 개인화 PDF** | 상담 후 발송. 역설적 신뢰 장치: 비교하려는 환자를 막지 않고 비교 기준을 제공(재료, 삭제량, 임시치아, 기공소, A/S 정책 등). 우리가 답할 수 있는 항목이 자연히 강점 |
| **삭제량·재료 투명 리포트** | 환자별 "무엇을 얼마나 삭제하고 어떤 재료로 하는지" 설계서 — 심미 환자의 최대 불안(과삭제) 해소 |

## 3. 결정 레이더 (Decision Radar) — 트래킹
- **개인 Smile Plan 링크**: 상담 후 환자별 고유 URL(시뮬레이션·견적·유사 케이스·FAQ). 열람 횟수, 체류 섹션, 재열람, **공유 여부(다른 기기/IP 열람 = 결정권자 개입 신호)** 기록
- **단계 스코어링**: 재열람 증가 → "결심 임박", 2주 무열람 → "타병원 비교/이탈 위험" 로 분류 → 직원에게 오늘의 연락 리스트로 노출
- **Objection 기반 시나리오**: 보류 사유별 후속 콘텐츠 자동 제안(가격→분납·단계 시술안, 두려움→임시치아 체험 케이스, 결정권자→동반 상담 초대)
- **상담 → 결정 소요일, 방문 횟수 분포** 학습 → 평균 대비 지연 환자 알림
- **"타병원 비교 중" 자기 신고 한 줄**(상담 마지막에 부담 없이): 비교 병원 수/기준을 태그로 → 이탈 사유 분석

## 4. 심미 취향 카드 (Aesthetic Profile)
- 내원 전 **이미지 취향 테스트**(웹, 2분): 치아 형태·밝기 사진 페어 선택 → 취향 점수화
- 레퍼런스(연예인/핀터레스트) 업로드, **"절대 싫은 것"** 수집
- 상담·기공소 의뢰서에 취향 카드 자동 첨부, **임시치아(mock-up) 승인 서명 기록** → 기대치 불일치 분쟁 예방
- 시술 단계별(프렙 직후·임시치아 기간) **불안 체크인 메시지** 자동화

## 5. 마케팅 트래킹 (유입 → 증거 소비 → 결정)
- **채널 어트리뷰션**: UTM/네이버 예약·플레이스 파라미터, **추적 전화번호**, 카톡채널 유입 링크, 대기실 QR 별 구분
- **콘텐츠→상담 연결**: 케이스 칼럼(블로그/유튜브/인스타)별로 어떤 글을 본 환자가 상담까지 갔는지 측정. 검색 의도 분리(라미네이트 vs 올세라믹 vs 치아성형 vs 앞니 교정)
- **퍼널 KPI**: 문의→상담예약→내원→견적→결정, 각 단계 전환율, 채널별 CAC, **결정까지 평균 접점 수**
- **증거 소비 분석**: 어떤 증거(유사케이스, 장기경과, 원장 포트폴리오)를 본 환자가 결정률이 높은가 → 마케팅 콘텐츠 우선순위 결정
- **조용한 추천 프로그램**: 심미 시술은 알리기 꺼리는 환자가 많음 → 비공개 개인 추천코드, 혜택은 현금성보다 관리 서비스(폴리싱·나이트가드)

## 6. 리텐션 & 장기 관리
- 시술 후 자동 일정: 1주·1개월 점검, 6개월 폴리싱, 야간 이갈이 나이트가드 교체, **5년 경과 촬영 초대**
- 변색·파절 사전 위험도(이갈이/흡연/커피) 기록 → 맞춤 관리 안내
- 후기 요청 대신 **"내 경과 기록" 포트폴리오** 제공(환자가 자기 변화를 보며 만족도 상승, 동의 시 사례로 환원)

## 7. 법·윤리 가드레일 (설계 단계부터 내장)
- 한국 의료법 광고 규제(치료경험담, 과장·비교 광고 제한, 전후 사진 표시 요건) 준수 — **공개 채널용 / 상담실 열람용 / 비공개 보관용** 케이스 권한 등급 분리
- 개인정보보호법상 건강정보는 **민감정보 → 별도 동의**, 사진 활용 범위·기간별 동의 + 철회 관리, 접근 로그
- 경험 수치는 근거 데이터 자동 보관(과장 방지), 법무/의료광고 심의 체크 단계 포함
- ⚠ 법적 사항은 구현 전 의료광고 전문 자문 필요(본 기획은 법률 자문이 아님)

## 8. 단계별 로드맵
- **Phase 1 (MVP, 4~6주)**: Patient/Case/Touchpoint 모델, 케이스 입력(표준 사진 업로드·태그), 유사 케이스 검색 + 상담 태블릿 뷰, 유입 채널 트래킹(UTM·추적번호), 동의 관리
- **Phase 2**: 개인 Smile Plan 링크 + 열람 트래킹, Decision Radar 스코어·오늘의 연락 리스트, 알림톡/카톡 자동화, 비교 체크리스트 PDF
- **Phase 3**: 취향 테스트·취향 카드, Longevity 리콜 자동화, 콘텐츠 어트리뷰션 대시보드, 추천 프로그램
- **Phase 4**: 차트 프로그램(덴트웹/이지덴 등) 연동, AI 유사 케이스 이미지 매칭, 상담 코칭 리포트

## 9. 제안 기술 스택 (가정 — 승인 시 조정)
- 웹앱: Next.js + TypeScript, PostgreSQL, 이미지 스토리지(암호화·서명 URL), 인증/권한(원장·상담실장·마케터 역할 분리)
- 메시징: 카카오 알림톡/친구톡 비즈 API 연동
- 트래킹: 자체 이벤트 로그 + 서버사이드 UTM 저장

## 검증 방법
- 샘플 데이터(가상 환자·케이스 50건 시드)로 유사 케이스 검색 정확도와 상담 뷰 시연
- Smile Plan 링크 열람/공유 이벤트가 Touchpoint에 정확히 기록되는지 E2E 테스트
- 동의 없는 케이스가 공개/상담 뷰에 노출되지 않는지 권한 테스트
- 어트리뷰션: UTM·추적번호 유입이 퍼널 대시보드에 올바르게 귀속되는지 확인

## 보완 A. 타깃 페르소나 & 고객 여정
**페르소나 (결정 기준이 다르므로 메시지·증거 우선순위를 분리)**
| 유형 | 특징 | 가장 먹히는 증거 |
|---|---|---|
| 이벤트형 (결혼·면접·촬영 D-day) | 일정 마감, 기간 민감 | 소요 기간·임시치아 일정 타임라인, 일정 보장 |
| 감도 높은 비교 쇼퍼 | 병원 3~5곳 상담, 사진·후기 정독 | 유사 케이스 수, 술자 포트폴리오, 삭제량 투명 리포트 |
| 재시술·불만족 경험자 | 이전 라미네이트 실패, 불신 | 장기 경과, A/S 정책, 재시술 케이스 |
| 결정권자 동반형 (배우자·부모 비용) | 설득 필요 | 공유용 요약 페이지, 동반 상담 초대 |
| 조용한 환자 (주변에 비공개) | 알림·문자 노출 꺼림 | 알림 문구 중립화, 비공개 추천 |

**여정 7단계와 CRM 개입점**: 검색/발견 → 증거 탐색(블로그·SNS) → 문의(카톡/전화/네이버예약) → 상담·진단 → 비교 기간(1~4주, 이탈 최다) → 결정·시술 → 사후·장기. 단계별로 "해야 할 한 가지 행동"을 정의(예: 비교 기간엔 *체크리스트 발송 + D+3 부담 없는 안부 1회*).

## 보완 B. 현장 운영 설계 (실패 원인 1순위: 입력 부담)
- **입력 최소화 원칙**: 케이스 입력은 시술 완료 시 *30초 이내*(태그 선택 + 표준 사진 일괄 업로드). 사진 파일명/EXIF·촬영 앱 템플릿으로 치아번호·시점 자동 분류.
- **과거 케이스 부트스트랩**: 신규 구축 직후엔 데이터가 0건이므로, 보유 사진을 일괄 업로드해 태깅하는 "백필 주간" + 케이스당 최소 필수 필드 3개만 요구. 동의 없는 과거 케이스는 *내부 통계용*으로만 쓰고 열람은 제한.
- **역할별 화면**: 원장(오늘 상담 환자 요약·유사 케이스), 상담실장(연락 리스트·보류 사유 입력), 코디네이터(경과 촬영 리콜·동의 수집), 마케터(채널·콘텐츠 대시보드).
- **상담 5분 전 브리핑 카드**: 유입 경로, 본 콘텐츠, 취향 카드, 비교 중 여부, 결정권자 → 상담 질을 균질화.
- **상담 스크립트 보조(선택)**: 보류 사유별 권장 응대를 안내하되 자동 발송은 직원 승인 후에만.

## 보완 C. 신뢰 보호 — "감시처럼 느껴지지 않게"
- 열람 추적·점수화는 **내부 참고용**, 환자에게 "봤죠?"식 연락 금지(자동 문구에서 열람 사실 언급 차단).
- 연락 빈도 상한(비교 기간 중 최대 2~3회), 수신 거부 1탭, 야간·주말 발송 차단.
- 알림톡 문구는 시술명 미노출 옵션("OO치과 상담 안내")으로 프라이버시 보호.
- 환자 본인 전용 "내 기록" 페이지에서 수집 정보를 열람·삭제 가능(오히려 신뢰 장치).
- 압박·희소성 마케팅("이번 주만") 자동화 제외 — 고감도 고객은 역효과.

## 보완 D. 지표 정의 (성공 기준)
- **North Star**: 심미 상담 → 결정 전환율(60일 내), 객단가 포함 시 *상담당 매출*
- **증거 지표**: 상담 시 유사 케이스 열람률, 열람 vs 비열람 환자 결정률 차이
- **비교 기간 지표**: 상담→결정 평균 일수, 비교 기간 이탈률, 사유별 분포
- **마케팅**: 채널별 CAC·상담 전환, 콘텐츠별 상담 기여, 증거 콘텐츠 소비 후 전환
- **운영**: 케이스 등록 완료율(시술 후 48h 내), 경과 촬영 회수율, 동의 확보율
- **리텐션**: 6개월 폴리싱 방문률, 5년 경과 촬영 회수, 추천 유입 비율
- 초기 3개월은 *기준선 측정*이 목표(개선율 목표는 그 후 설정).

## 보완 G. 기존 설문지(APRO 심미보철 통합 상담 설문지) 반영
**현재 설문의 강점**: 6문항으로 짧고, 색상·모양을 그림으로 고르게 해 심미 환자의 감각에 맞음. 그대로 디지털화해 CRM 입력 소스로 사용.

**문항 → CRM 데이터 매핑**
| 문항 | CRM 필드 | 활용 |
|---|---|---|
| 01 개선 부위 | `concerns[]` (벌어진 앞니, 파절·마모, 크기·모양, 덧니·배열, 변색, 잇몸노출, 왜소치, 백색반점, 기존 보철 재작업) | **유사 케이스 매칭 키**, 상담 브리핑, 콘텐츠 추천 |
| 02 치아 개수 (상/하) | `arch_upper/lower_count` | 견적 범위·케이스 매칭(개수대 유사), 상담 시간 배정 |
| 03 색상·모양·변화 정도 | `AestheticProfile` (shade 단계, 형태 3종, 변화 강도) | 취향 카드, 기공소 의뢰서, mock-up 기준 |
| 04 불편함 | `symptoms[]` | 치료 범위 확장(교합·TMD 병행) 판단, 위험 플래그 |
| 05 습관 | `habits[]` (이갈이·악물기·손톱·딱딱한 음식) | 재료 선택(파절 위험), 나이트가드 제안, 관리 리콜 |
| 06 레퍼런스 | `reference_assets[]` | 사진 업로드 링크 자동 발송 |

**개선·수정 제안 (우선순위 순)**
1. **개선 부위 1순위 표시**: Q1은 복수 선택인데 "가장 신경 쓰이는 1개"를 별도로 고르게 → 상담 첫 5분의 초점 결정.
2. **유입·비교 정보 추가 (가장 중요한 누락)**: "어떻게 알게 되셨나요?"(채널 선택 + 검색어/콘텐츠 자유기입), "다른 병원 상담 받아보셨나요? (몇 곳 / 아직)", "병원 선택 시 가장 중요한 기준 1~2개"(경험·원장·가격·디자인·사후관리·일정). → 트래킹과 비교 단계 파악의 핵심 데이터.
3. **일정 질문**: "희망 시기가 있나요?"(결혼·행사·촬영·면접 등 / 여유) → 이벤트형 페르소나 분류.
4. **이전 시술 경험**: 라미네이트/보철 경험 유무, 불만족 여부·이유 → 재시술 환자 응대, 가장 큰 불신 요인 파악.
5. **의사결정 구조**: "상담에 함께 오시거나 의견을 나누실 분이 있나요?" → 결정권자 동반 상담 초대, 공유용 페이지.
6. **예산 감각은 직접 금액 대신 완곡하게**: "비용 방식 선호"(한 번에 / 단계별 / 분납) 정도만. 노골적인 예산 질문은 감도 높은 환자에게 거부감 가능.
7. **연락 선호**: 선호 채널(카톡/문자/전화), 가능 시간대, "시술명 노출 없는 메시지 선호" 체크 → 조용한 환자 보호.
8. **직업 문항 재설계**: 직업은 민감하게 느낄 수 있어 "치아 외모가 중요한 활동(촬영·방송·접객·발표 등)" 선택형으로 대체/보완.
9. **디자인 선택 시각화 개선**: 색상은 4단계에 `shade` 코드(BL1~A2 등) 내부 매핑 추가, 모양은 상악 6전치 외 **치아 길이·너비 비율, 가장자리 투명도** 선택지 추가(선택 사항). 사진 대신 *내 사진 위에 시뮬레이션*을 보여주는 방식으로 Phase 3에서 고도화. "의료진 추천"은 취향 데이터 손실이므로 선택 시 후속 질문("자연스러움 vs 화사함 중 어디에 가까운 편?")으로 보강.
10. **변화 정도 슬라이더화**: 3개 선택지 → 5점 척도(자연스럽게 ~ 확실하게)로 세분화해 기대치 편차 감지. 기대치가 높고 "자연스럽게"를 동시에 선택하는 모순 응답은 상담 플래그.
11. **"싫은 것" 질문 신설**: "이런 느낌은 피하고 싶어요"(인위적으로 하얀, 너무 큰 치아, 일자 배열 등) — 심미 환자의 실패 공포를 직접 포착.
12. **동의 분리**: 설문 하단에 (필수) 상담 목적 개인정보·건강정보 수집, (선택) 사진 촬영·시뮬레이션, (선택) 케이스 활용 범위, (선택) 마케팅 수신 — 체크박스 분리.
13. **연락처 수집 시점**: 사전 웹 설문은 연락처를 마지막 단계로 이동(이탈 감소), 이름은 닉네임 허용.

**디지털 설문 UX 원칙**
- 사전 웹 설문(예약 확정 시 링크) + 내원 시 태블릿 보완 입력 + 종이 설문 스캔 백업(고령/현장 대응).
- 6문항 → 이미지 카드 선택 위주 약 2분, 진행 바, 모바일 우선, 응답 자동 저장.
- 응답 완료 시 **상담 전 브리핑 카드**와 취향 카드 자동 생성(보완 B 연동), 응답 요약을 환자에게 되돌려 보여 "내 말을 들어줬다"는 경험 제공.
- 모순·고위험 응답 자동 플래그: 이갈이+파절 우려(재료 상담), 높은 변화 기대+자연스러움 동시 선택, 재시술 불만족 이력.
